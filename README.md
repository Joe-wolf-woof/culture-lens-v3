# 拡張翻訳 - CultureLens（MVP）【v3クローン：質問モード段階的開示バージョン】

## バージョン構成（2026-11-18〜）

ユーザテストで仕様の違いによる反応を比べられるよう、3つのバージョンを並行して保持する。

- ① オリジナル（本番 `culture-lens`）：見せるのみ。質問モードなし
- ② v2クローン（`extended-translation-window-v2`）：質問モードの全面的開示バージョン（独立パネルが常時開ける）
- ③ v3クローン（本リポジトリ）：質問モードの段階的開示バージョン（入口はタグとフックだけ）

> これは本番（culture-lens）系統の3つ目のクローンです（2026-11-18 作成）。v2クローンを土台に、質問モードの「段階的開示」だけを変更した比較用バージョンです。

JOEの超長期ビジョンの第一実験機。
「言語の翻訳」ではなく、映像の中の風景やモノの背景にある**文化・歴史・語り手の感情**までを空間上に視覚化するWebARプロトタイプ。

## 体験フロー（最初の実験：日本のディープな日常を英語圏へ）

1. スマホでこのページを開き「📷 カメラ起動」
2. 語り手（JOE）が日本の日常・路地裏・チャイを淹れる手元などを映し、「🎙 語る」で自分の言葉で数秒語る（手入力も可）
3. 「🌐 拡張翻訳する」→ カメラフレーム＋語りをGeminiへ送信
4. 画面に英語の拡張字幕＋「異文化の背景知識タグ」がThree.jsで空間にピン留め表示される

APIキーが無い場合は「デモデータで試す」にチェックすると、チャイのサンプルデータで全UIを確認できる。

## 設計

- `index.html` / `css/style.css` — UI（カメラステージ、字幕、タグカード）
- `main.js` — カメラ、音声認識、Three.js空間タグの配線
- `engine/translate-engine.js` — 拡張翻訳エンジン。プロンプトに心理学の仕掛けを組み込み済み：
- 情報ギャップ理論（Loewenstein）：驚きのギャップは1つに絞る
- 自己関連効果：受け手の日常と接続する一文を必須化
- 具体性効果：抽象論ではなく感覚（匂い・手触り・音・温度）で語る
- Geminiモデルフォールバック（3.x系→、404/429/503で次モデルへ）はHowLinkと同方式

## ローカル起動

```bash
cd extended-translation-window
python3 -m http.server 8080
# スマホからは https または localhost が必要（カメラ・マイクの制約）
```

## 注意

- Gemini APIキーは設定画面から入力し、端末のlocalStorageにのみ保存される。コードやリポジトリには含めない。
- 空間タグは視覚トラッキング付き：撮影フレームから各タグ位置の画像パッチを切り出し、現在の映像内で正規化相関が最大の位置へアンカーを追従させる（回転・移動の両方に対応）。見失いが続くタグは自動で隠し、全て見失うか処理負荷が高い状態が続いたら全ラベルを非表示にする（発熱・重さ対策）。大幅な画角変更や見た目の変化では追跡が外れることがある（2Dカメラのみ、専用ゴーグルなし）。

## 言語切替・見比べ機能（v2で追加、2026-11-18）

翻訳結果の英文を日本語に切り替えて見比べられるようにする、案A＋Dの併用実装。

- **エンジン**：Gemini に英語フィールドと対になる日本語フィールド（`*_ja`）を同時生成させる。追加のAPI呼び出しはなく、待ち時間は増えない。日本語版にも【事実の扱い】ルール（来歴の創作禁止）を適用。モック（デモデータ）にも日本語版を用意した。
- **案A（トグルチップ）**：カメラ画面右上の「EN / あ」チップで、字幕・空間タグ・タグカード・ギャップ／フックの表示言語を一括切替する。空間タグは配置と視覚トラッキングを維持したまま、ラベルのテクスチャだけを描き直す。読み上げも表示言語に連動する。選択は localStorage（`etw_result_lang`）に保存される。
- **案D（見比べシート）**：「🔍 EN・日本語で見比べる」ボタンで、直訳／拡張翻訳／各タグ／文化ギャップ／好奇心フックを EN・日本語の対照で一覧表示するシートを開く。

## カメラ ON/OFF トグル（v2で追加、2026-11-18）

- 「📷 カメラ起動」ボタンを「📷 ON / 📷 OFF」トグルに変更。OFFにすると映像・空間タグ・視覚トラッキングを止める（録音中なら音声入力も停止）。
- OFFの間も翻訳結果（字幕・タグカード・ギャップ／フック・見比べシート）はそのまま読める。再度ONにすると空間タグは静止表示で戻り、追従は次回の「拡張翻訳する」で再開する。

## UI改善（2026-11-18、JOE指示）

- ① カメラボタンの表示を「押すとどうなるか」に変更：カメラON中は「📷 OFF」、停止中は「📷 ON」。
- ② 「🌐拡張翻訳(EN/あ)」ボタンを 📷ボタンと 🎙ボタンの間に配置し、3ボタンを横一列（折り返しなし）にした。
- ③ 入力欄ラベルを「翻訳する方法→📷カメラに映す/🎙話しかける/📝手入力する」に変更。
- ④ 「🔍 EN・日本語で見比べる」ボタンの背景を白にして可視性を上げた。

## 質問モード【v3：段階的開示】（双方向ライブ化、2026-11-18）

- CultureLens のコンセプトは「カメラに映る物を文化背景ごと翻訳するツール」。想定ユーザーは観光客や見慣れぬ土地に来た人で、狙いは ①親近感 ②安心感 ③好奇心。
- 「双方向」の相手は話者ではなく目の前の物／文化。質問モードでは、カメラに映る物について質問すると `askAboutScene` が現在のフレーム＋直前の拡張翻訳結果を文脈に、文化背景ごとの答えと「次に聞きたくなる質問」を返す。
- **v3の変更点は開示の仕方だけ**（エンジンはv2と同一）。v2では質問モードの独立パネルが常時開けてUIが複雑化し、「何をするアプリか」の印象まで複雑になった。v3では通常画面から質問UIを消し、入口を2つだけに絞った：
  - タグカードの「❓ これについて聞く」（対象をそのタグに絞って質問シートが開く）
  - 好奇心フックの「❓ この問いを深掘りする」（フックの問いがそのまま最初の質問になる）
- 質問と回答のやり取りはモーダルの質問シートに集約される。シート内では音声（日本語／英語）・テキストでの追加質問と「次の質問」チップの連鎖が使える。
- 事実の扱い（画像に無いこと・来歴を創作しない）は景色モードと同じ接地ルール。APIキーが無い／デモモードではモック応答でUIを確認できる。
- 本番 culture-lens には未反映。ユーザテストで ①②③ を比較し、採用する仕様を決める。
